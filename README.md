# 🧠 MindPlay V1.1

ศูนย์รวมเกมอ่านใจภาษาไทย เล่นฟรีผ่านเว็บไซต์

## V1.1
- เปิดเกมแรก: อ่านตัวเลขในใจ 1–100
- ผู้เล่นไม่ต้องพิมพ์เลขที่เลือก
- คำถามแบบ Binary 7 รอบ
- สุ่มลำดับคำถามและตำแหน่งตัวเลข
- Progress 1/7 ถึง 7/7
- หน้าอ่านความคิดและ Reveal Animation
- รองรับกรณีทายถูก/ลองใหม่
- Mobile First และไม่ใช้กล้อง/ไมค์
- หน้าแรกอัปเดตปุ่มเล่นเกมและ Badge ใหม่

## เทคโนโลยี
- Next.js 16
- React 19
- TypeScript
- Vercel

## เริ่มต้น
```bash
npm install
npm run dev
```
